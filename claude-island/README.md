# Claude Island — «чёлка» для Claude Code на Windows

Плашка вверху экрана показывает, чем сейчас занят Claude Code:

- **этапы**: Чтение → Правка → Тесты → Готово;
- **живой ползунок**: переливается, «дышит», рассыпает искры и пружинит при переходе на новый этап;
- **таймер** задачи, имя проекта, текущее действие («Правлю cart.js», «Запускаю тесты»);
- **ваша задача** в облачке, а в конце — **ответ Claude**, который печатается по буквам;
- в конце всё **становится зелёным, по полоске пробегает волна, и плашка плавно исчезает**;
- когда Claude ждёт разрешения, плашка мигает жёлтым.

Плашка не перехватывает клики: под ней можно работать как обычно.

## Установка (обычный способ)

1. Скачайте `Claude-Island-Setup-*.exe`. Его собирает GitHub Actions: вкладка **Actions** → «Claude Island — сборка для Windows» → последний запуск → **Artifacts**.
2. Запустите установщик. Windows может предупредить «неизвестный издатель», потому что у программы нет платной подписи. Нажмите «Подробнее» → «Выполнить в любом случае».
3. При первом запуске приложение само:
   - подключается к Claude Code (добавляет хуки в `%USERPROFILE%\.claude\settings.json`, ваши хуки не трогает);
   - включает запуск вместе с Windows;
   - показывает проверочную плашку.
4. **Перезапустите Claude Code** — готово.

Нужен установленный [Node.js](https://nodejs.org): через него Claude Code передаёт события плашке.

Если не хотите ничего устанавливать, есть `Claude-Island-Portable-*.exe`. Он запускается без установки.

## Меню в трее

Значок — тёмный квадрат с ползунком возле часов. Щелчок по нему показывает проверку. Правый щелчок открывает меню:

- **Показать проверку** — демо-прогон плашки;
- **Пауза** — временно не показывать плашку;
- **Запускать вместе с Windows**;
- **Подключить / Отключить от Claude Code**;
- **Открыть журнал** — если что-то не работает;
- **Выход**.

## Запуск из исходников

```bat
cd claude-island
npm install
npm start
```

Другие команды:
- `npm run demo` — демо по кругу;
- `npm run debug` — видимое окно с инструментами разработчика;
- `npm run dist` — собрать `.exe` локально (на Windows).

Проверка без Claude Code: откройте http://127.0.0.1:47321/test.

## Как это устроено

| Файл | Что делает |
|---|---|
| `hook.js` | Хук Claude Code. Копируется в `~/.claude/claude-island-hook.js`, отправляет событие плашке на `127.0.0.1:47321` и сразу завершается. Если плашка не запущена, ничего не ломается. |
| `main.js` | Electron: прозрачное окно поверх всех, значок в трее, автозапуск, приёмник событий (только localhost). |
| `hooks-config.js` | Подключение и отключение хуков в настройках Claude Code. Перед изменением делает резервную копию. |
| `renderer/` | Плашка и ползунок на canvas. |

Как выбирается этап:
- `Read`, `Grep`, `Glob`, `WebSearch` → **Чтение**;
- `Edit`, `Write` → **Правка**;
- `Bash` с `npm test`, `pytest`, `jest`, `go test` и т. п. → **Тесты**;
- конец ответа (хук `Stop`) → **Готово**.

Внутри этапа ползунок не стоит на месте, а медленно ползёт вперёд.

## Удаление

1. В меню трея выберите «Отключить от Claude Code».
2. Удалите программу через «Параметры → Приложения».
