# Claude Island — «чёлка» для Claude Code на Windows

Плашка вверху экрана показывает, чем сейчас занят Claude Code:

- **этапы**: Чтение → Правка → Тесты → Готово;
- **живой ползунок**: переливается, «дышит», рассыпает искры и пружинит при переходе на новый этап;
- **таймер** задачи, имя проекта, текущее действие («Правлю cart.js», «Запускаю тесты»);
- **твоя задача** в облачке, а в конце — **ответ Claude**, который печатается по буквам;
- в конце всё **становится зелёным, по полоске пробегает волна, и плашка плавно исчезает**;
- когда Claude ждёт разрешения, плашка мигает жёлтым.

Плашка не перехватывает клики: под ней можно работать как обычно.

Демо: [`demo.webm`](demo.webm).

## Установка

Нужен [Node.js](https://nodejs.org) 18+.

```bat
cd claude-island
npm install
npm run install-hooks
npm start
```

`npm run install-hooks` добавляет хуки в `%USERPROFILE%\.claude\settings.json`. Перед этим он делает резервную копию, а ваши хуки оставляет как есть. После установки **перезапустите Claude Code**.

Посмотреть без Claude Code: `npm run demo`.

Удалить хуки: `npm run uninstall-hooks`.

## Автозапуск вместе с Windows

1. Нажмите `Win + R`, введите `shell:startup`.
2. Положите туда ярлык на `start.bat` из этой папки.

## Как это устроено

| Файл | Что делает |
|---|---|
| `hook.js` | Хук Claude Code. Отправляет событие плашке на `127.0.0.1:47321` и сразу завершается. Если плашка не запущена, ничего не ломается. |
| `main.js` | Electron: прозрачное окно поверх всех окон и приёмник событий (только localhost). |
| `renderer/` | Плашка и ползунок на canvas. |
| `install-hooks.js` | Добавляет и убирает хуки в настройках Claude Code. |

Как выбирается этап:
- `Read`, `Grep`, `Glob`, `WebSearch` → **Чтение**;
- `Edit`, `Write` → **Правка**;
- `Bash` с `npm test`, `pytest`, `jest`, `go test` и т. п. → **Тесты**;
- конец ответа Claude (хук `Stop`) → **Готово**.

Внутри этапа ползунок не стоит на месте, а медленно ползёт вперёд.

Порт можно поменять через переменную окружения `CLAUDE_ISLAND_PORT`. Задайте одно и то же значение и для плашки, и для Claude Code.
