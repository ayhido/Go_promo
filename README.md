# GoPromo CRM + ИИ-диспетчер «мастер на час»

Что внутри:

- **`/`**: 3D-сайт для клиентов (JARVIS-сфера, услуги и цены, форма заявки, кнопка Telegram).
- **`/crm`**: CRM кандидатов (отклики, импорт, Excel, Telegram).
- **Telegram-бот для клиентов**: клиент сам оставляет заявку, получает контакты мастера и статусы, ставит оценку.
- **`/dispatcher`**: ИИ-диспетчер заказов в духе JARVIS. Принимает заявку клиента текстом или голосом, заводит заказ, оценивает цену, сам назначает мастера и показывает, какие заказы ждут вашей реакции.

## Запуск

1. Установите Node.js 20 или новее (https://nodejs.org).
2. Скопируйте `.env.example` в `.env` и впишите туда `TG_TOKEN` и `TG_CHAT_ID`. Это работает одинаково на Windows, Mac и Linux.
3. В папке проекта:

```bash
npm install
npm start            # http://localhost:3000/dispatcher
```

В консоли должно появиться `Telegram: бот @имя_бота подключён`. Пока окно с программой открыто, бот отвечает клиентам.

При первом запуске программа сама придумает **пароль для панели**, покажет его в окне и сохранит в `.env` (строка `ADMIN_PASSWORD`). Пароль можно поменять в `.env`.

## Безопасность

- Панель `/dispatcher`, CRM `/crm` и все их API доступны только после входа по паролю (страница `/login`). Сессия хранится в cookie `HttpOnly; SameSite=Strict` неделю.
- Подбор пароля: после 8 неверных попыток с одного адреса вход блокируется на 15 минут, попытки пишутся в консоль.
- Публично открыты только сайт, его форма заявки и webhook Telegram.
- Форма на сайте: не больше 5 заявок в час с одного адреса, скрытое поле-ловушка для спам-ботов, проверка телефона и длины текста.
- Кнопки мастеров в Telegram работают только у назначенного мастера; клиент видит и отменяет только свои заявки.
- Заголовки защиты: запрет встраивания в чужие сайты (`X-Frame-Options`), `nosniff`, `Referrer-Policy`.
- Если сайт стоит за nginx или другим прокси, поставьте `TRUST_PROXY=1`, чтобы лимиты считались по настоящему IP клиента.

## Деньги, отказы, отмены

- **Выполнен**: мастер в Telegram нажимает «🏁 Выполнен» и пишет, сколько взял с клиента. В панели — кнопка «✔ Выполнен», она спросит сумму. Закрыть заказ без суммы нельзя.
- **Отказ** (клиент отказался на месте): мастер выбирает причину (дорого, передумал, не дозвонился, не смог сделать) и пишет, сколько взял за выезд (можно 0).
- **Отмена** (до выезда): в панели кнопка «✕» с причиной; клиент может отменить сам в боте.
- **«Не могу»**: мастер отказывается от заказа, заказ автоматически уходит следующему свободному мастеру.
- Касса за день, доля компании (`COMMISSION_PERCENT`) и заработок каждого мастера видны в панели, в «сводке» и у мастера по команде `/master`. В Excel-выгрузке есть колонки «Взято», «Доля компании», «Причина».

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `ANTHROPIC_API_KEY` | Разбор заявок через Claude (точнее понимает свободный текст). Без ключа работает разбор правилами. |
| `AI_MODEL` | Модель Claude, по умолчанию `claude-opus-5-5`. |
| `AI_DISABLED=1` | Принудительно отключить ИИ. |
| `TG_TOKEN` | Токен бота от @BotFather. Один бот на всё: клиенты, мастера, уведомления. |
| `TG_CHAT_ID` | Чат или группа операторов: новые заказы, фото, просьбы связаться, низкие оценки. |
| `TG_POLLING=1` | Бот сам опрашивает Telegram, webhook и публичный адрес не нужны. Удобно для запуска на своём компьютере. |
| `TG_PROXY` | Прокси для запросов к Telegram (`http://127.0.0.1:10809` или `socks5://…`), если провайдер блокирует api.telegram.org. На Windows системный прокси VPN-программы подхватывается автоматически. |
| `TG_WEBHOOK_SECRET` | Секрет webhook: запросы без него на `/telegram-webhook` отклоняются. |
| `ADMIN_PASSWORD` | Пароль для входа в панель. Если не задан — создаётся при первом запуске. |
| `COMMISSION_PERCENT` | Доля компании с выполненного заказа, % (например, 30). 0 — не считать. |
| `SITE_NAME`, `SITE_CITY`, `SITE_PHONE` | Название, город и телефон на сайте для клиентов. |
| `TRUST_PROXY=1` | Сайт работает за nginx/прокси: брать IP клиента из заголовков. |
| `DEFAULT_CITY` | Город по умолчанию, если в заявке его нет. |
| `ATTENTION_MIN` | Через сколько минут неназначенный заказ попадает в «Требует внимания» (по умолчанию 15). |
| `DATA_DIR` | Папка для `db.json` с заказами и мастерами (по умолчанию `./data`). |

## Как работает диспетчер

1. **Заявка → заказ.** Из свободного текста («Течёт кран, Москва, ул. Ленина 5 кв 12, завтра после 18, Анна +7 999…») извлекаются категория работ, город, адрес, время, имя, телефон и срочность. Также считается ориентир цены (за срочность +50%).
2. **Автоназначение.** Подбирается активный мастер из того же города с нужным навыком (или «Универсал»), у которого меньше всего заказов в работе и выше рейтинг. Когда добавляется новый мастер, он сразу забирает ждущие заказы.
3. **«Требует внимания».** Сюда попадают заказы, которые долго ждут мастера, заказы без свободного мастера, без телефона или адреса, срочные заказы и заказы, где время визита прошло, а работа не началась.
4. **Мастер в Telegram.** Если у мастера указан `tgChatId`, он получает заказ с кнопками «Беру» и «Выполнен». Кнопки работают и через webhook, и в режиме `TG_POLLING=1`, нажать их может только назначенный мастер.
5. **Голос.** Кнопка 🎙 распознаёт речь (Chrome), «озвучивать» включает ответы голосом.

## Telegram-бот для клиентов

### Как подключить

1. В Telegram откройте @BotFather, выполните `/newbot` и получите токен. Это `TG_TOKEN`.
2. Узнайте id чата операторов (например, добавьте бота в группу и посмотрите id через @getidsbot). Это `TG_CHAT_ID`.
3. Запуск одним из двух способов:
   - **Просто (без домена):** в `.env` укажите `TG_POLLING=1` и запустите `npm start`.
   - **На сервере с HTTPS-доменом:** поставьте webhook:
     `https://api.telegram.org/bot<TG_TOKEN>/setWebhook?url=https://ваш-домен/telegram-webhook&secret_token=<TG_WEBHOOK_SECRET>`
4. Мастерам: в панели `/dispatcher` укажите у мастера его Telegram chat id. Мастер должен один раз написать боту `/start`, иначе Telegram не даст боту написать ему первым.

### Что видит клиент

- `/start`: приветствие и меню «🛠 Оставить заявку», «📋 Мои заказы», «💰 Цены», «📞 Связаться с оператором».
- Можно сразу написать проблему своими словами, можно с фото. Бот сам разберёт текст, а недостающее спросит по шагам: город, адрес, время, телефон (кнопкой «📱 Отправить мой номер»).
- Перед отправкой показывает карточку заявки с ориентиром цены и кнопкой подтверждения.
- После отправки приходят контакты мастера, затем уведомления «мастер приступил» и «выполнено» с оценкой от 1 до 5. Оценки 3 и ниже сразу уходят операторам.
- В «Моих заказах» можно отменить заявку, пока мастер не начал работу.

### Команды в чате диспетчера

- `сводка`: цифры за сегодня.
- `что требует внимания` / `что горит`: список проблемных заказов.
- `мастера`: кто на линии и сколько у кого заказов.
- `заказ 5`: карточка заказа.
- `5 в работе`, `5 выполнен 3500`, `5 отказ дорого 500`, `отмени 5 клиент передумал`: смена статуса с суммой и причиной.
- `назначь 5 на Ивана`: ручное назначение.
- Любой другой текст считается заявкой клиента.

## API

`POST /api/dispatcher/chat {text}`, `GET/POST /api/orders`, `PATCH /api/orders/:id`, `POST /api/orders/:id/assign {masterId?}`, `GET/POST /api/masters`, `PATCH /api/masters/:id`, `GET /api/orders/export` (Excel), `GET /api/events` (SSE для живого обновления).
