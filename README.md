# GoPromo CRM + ИИ-диспетчер «мастер на час»

Три части:

- **`/`**: CRM кандидатов (отклики, импорт, Excel, Telegram).
- **`/tseh`**: «Цех», конвейер Reels. Сам пишет сценарий, озвучивает, собирает 3D-ролик с субтитрами, музыкой и звуковыми эффектами, пишет пост и выкладывает в Instagram. Ведёт несколько роликов одновременно.
- **`/dispatcher`**: ИИ-диспетчер заказов в духе JARVIS. Принимает заявку клиента текстом или голосом, заводит заказ, оценивает цену, сам назначает мастера и показывает, какие заказы ждут вашей реакции.

## Запуск

```bash
npm install
npm run setup        # голос (edge-tts) и Chromium для 3D-рендера; нужен ffmpeg и python3
npm start            # http://localhost:3000/tseh и http://localhost:3000/dispatcher
npm run reels -- --count 3            # снять 3 ролика из консоли
npm run reels -- --topic "Как не залить соседей"
```

## «Цех»: Reels на конвейере

Каждый ролик идёт по этапам **Сценарий → Голос → Раскадровка → Сборка → Пост → Публикация**, карточки обновляются вживую.

- **Сценарий.** С `ANTHROPIC_API_KEY` Claude пишет новый сценарий под тему или придумывает её сам: крючок в первые 2 секунды, живая речь, юмор и эмоции, позитивный финал, призыв. Без ключа берутся 8 готовых сценариев из `reels/library.js` под нишу «мастер на час».
- **Голос.** Каждая сцена озвучивается со своей интонацией (крючок быстрее и выше, «боль» ниже). Бесплатно через нейроголос Microsoft (`ru-RU-DmitryNeural`), эмоциональнее через ElevenLabs.
- **3D.** Three.js рендерит 1080×1920, 30 fps: глянцевые 3D-предметы (капля, молоток, дом, молния, сердце, часы, монета…), летающие карточки, счётчик цифр, телефон с призывом, конфетти, «живая» камера. Субтитры слово в слово, текущее слово подсвечено.
- **Музыка.** Синтезируется под каждый ролик (мажорная прогрессия, своё BPM и тональность), приседает под голос. Авторских прав нет.
- **Звуковые эффекты** (`reels/sfx.js`). Расставляются сами по раскадровке: удар на крючке, свуш на каждой склейке, «поп» на появлении карточек и пунктов, тики счётчика и «дзынь» на цифре, хлопушка с искрами под конфетти, подъём перед призывом, лёгкие тапы на фразах. Тоже синтез, без чужих сэмплов.
- **Публикация.** По умолчанию ролик ждёт тебя («Ждёт тебя»): смотришь, правишь подпись, жмёшь «Выложить». Галочка «выкладывать без меня» или автопилот в «Пульте» выкладывают сами.
- **Автопилот.** В «Пульте» задай время (`10:00, 14:00, 19:00`) и сколько роликов за раз.
- **Замеры.** Просмотры, охват, лайки, сохранения и репосты через 24 часа после публикации.

Рендер тяжёлый: примерно 8 минут на 30-секундный ролик на 2 ядрах. Параллельно собирается `REELS_RENDER_PARALLEL` роликов, остальные ждут «монтажный стол».

### Подключить Instagram

1. Аккаунт Instagram переводится в профессиональный (Business или Creator).
2. В [Meta for Developers](https://developers.facebook.com/) создаётся приложение с продуктом Instagram и разрешениями `instagram_business_basic` и `instagram_business_content_publish` (или `instagram_content_publish` при входе через Facebook).
3. Выпускается долгоживущий токен, и задаются `IG_USER_ID`, `IG_ACCESS_TOKEN`. Для токена от входа через Instagram ещё `IG_GRAPH_HOST=graph.instagram.com`.

Видео заливается напрямую (resumable upload), публичный адрес сервера не нужен. Лимит Instagram: 50 публикаций через API в сутки.

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `ANTHROPIC_API_KEY` | Разбор заявок и сценарии рилсов через Claude. Без ключа: разбор правилами и библиотека сценариев. |
| `IG_USER_ID`, `IG_ACCESS_TOKEN` | Публикация Reels в Instagram. |
| `IG_GRAPH_HOST`, `IG_API_VERSION` | `graph.facebook.com` (по умолчанию) или `graph.instagram.com`; версия API, по умолчанию `v21.0`. |
| `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID` | Самый живой и эмоциональный голос. Без ключа: бесплатный нейроголос. |
| `REELS_VOICE` | Голос edge-tts: `ru-RU-DmitryNeural` (по умолчанию) или `ru-RU-SvetlanaNeural`. `REELS_TTS=none` без голоса. |
| `REELS_SFX=0`, `REELS_SFX_LEVEL` | Выключить звуковые эффекты / громкость эффектов (по умолчанию 1). |
| `REELS_RENDER_PARALLEL` | Сколько роликов рендерится одновременно (по умолчанию 2). |
| `REELS_NICHE`, `REELS_BRAND`, `REELS_HANDLE`, `REELS_AUTOPILOT`, `REELS_PER_RUN`, `REELS_AUTOPUBLISH=1` | Начальные настройки «Пульта». |
| `AI_MODEL` | Модель Claude, по умолчанию `claude-opus-5-5`. |
| `AI_DISABLED=1` | Принудительно отключить ИИ. |
| `TG_TOKEN`, `TG_CHAT_ID` | Уведомления о заказах в общий Telegram-чат. |
| `DEFAULT_CITY` | Город по умолчанию, если в заявке его нет. |
| `ATTENTION_MIN` | Через сколько минут неназначенный заказ попадает в «Требует внимания» (по умолчанию 15). |
| `DATA_DIR` | Папка для `db.json` с заказами и мастерами (по умолчанию `./data`). |

## Как работает диспетчер

1. **Заявка → заказ.** Из свободного текста («Течёт кран, Москва, ул. Ленина 5 кв 12, завтра после 18, Анна +7 999…») извлекаются категория работ, город, адрес, время, имя, телефон и срочность. Также считается ориентир цены (за срочность +50%).
2. **Автоназначение.** Подбирается активный мастер из того же города с нужным навыком (или «Универсал»), у которого меньше всего заказов в работе и выше рейтинг. Когда добавляется новый мастер, он сразу забирает ждущие заказы.
3. **«Требует внимания».** Сюда попадают заказы, которые долго ждут мастера, заказы без свободного мастера, без телефона или адреса, срочные заказы и заказы, где время визита прошло, а работа не началась.
4. **Мастер в Telegram.** Если у мастера указан `tgChatId`, он получает заказ с кнопками «Беру» и «Выполнен». Для этого нужен webhook бота на `/telegram-webhook`.
5. **Голос.** Кнопка 🎙 распознаёт речь (Chrome), «озвучивать» включает ответы голосом.

### Команды в чате

- `сводка`: цифры за сегодня.
- `что требует внимания` / `что горит`: список проблемных заказов.
- `мастера`: кто на линии и сколько у кого заказов.
- `заказ 5`: карточка заказа.
- `5 в работе`, `5 выполнен`, `отмени заказ 5`: смена статуса.
- `назначь 5 на Ивана`: ручное назначение.
- Любой другой текст считается заявкой клиента.

## API

`POST /api/dispatcher/chat {text}`, `GET/POST /api/orders`, `PATCH /api/orders/:id`, `POST /api/orders/:id/assign {masterId?}`, `GET/POST /api/masters`, `PATCH /api/masters/:id`, `GET /api/orders/export` (Excel), `GET /api/events` (SSE для живого обновления).
