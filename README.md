# GoPromo CRM + ИИ-диспетчер «мастер на час»

Три части:

- **`/radar`**: «Радар заработка» — приложение для телефона: новые идеи заработка, бизнесы, тренды, инвестиции и рилсы с push-уведомлениями; собирает видео рилсов и публикует их в Instagram.
- **`/`**: CRM кандидатов (отклики, импорт, Excel, Telegram).
- **`/dispatcher`**: ИИ-диспетчер заказов в духе JARVIS. Принимает заявку клиента текстом или голосом, заводит заказ, оценивает цену, сам назначает мастера и показывает, какие заказы ждут вашей реакции.

## Запуск

```bash
npm install
npm start            # http://localhost:3000/dispatcher
```

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `ANTHROPIC_API_KEY` | Разбор заявок через Claude (точнее понимает свободный текст). Без ключа работает разбор правилами. |
| `AI_MODEL` | Модель Claude, по умолчанию `claude-opus-5-5`. |
| `AI_DISABLED=1` | Принудительно отключить ИИ. |
| `TG_TOKEN`, `TG_CHAT_ID` | Уведомления о заказах в общий Telegram-чат. |
| `DEFAULT_CITY` | Город по умолчанию, если в заявке его нет. |
| `ATTENTION_MIN` | Через сколько минут неназначенный заказ попадает в «Требует внимания» (по умолчанию 15). |
| `DATA_DIR` | Папка для `db.json` с заказами и мастерами (по умолчанию `./data`). |

## Как работает диспетчер

1. **Заявка → заказ.** Из свободного текста («Течёт кран, Москва, ул. Ленина 5 кв 12, завтра после 18, Анна +7 999…») извлекаются категория работ, город, адрес, время, имя, телефон и срочность. Также считается ориентир цены (за срочность +50%).
2. **Автоназначение.** Подбирается активный мастер из того же города с нужным навыком (или «Универсал»), у которого меньше всего заказов в работе и выше рейтинг. Когда добавляется новый мастер, он сразу забирает ждущие заказы.
3. **«Требует внимания».** Сюда попадают заказы, которые долго ждут мастера, заказы без свободного мастера, без телефона или адреса, срочные заказы и заказы, где время визита прошло, а работа не началась.
4. **Мастер в Telegram.** Если у мастера указан `tgChatId`, он получает заказ с кнопками «Беру» и «Выполнен». Для этого нужен webhook бота на `/telegram-webhook`.
5. **Голос.** Кнопка 🎙 распознаёт речь (Chrome), «озвучивать» включает ответы голосом.

### Команды в чате

- `сводка`: цифры за сегодня.
- `что требует внимания` / `что горит`: список проблемных заказов.
- `мастера`: кто на линии и сколько у кого заказов.
- `заказ 5`: карточка заказа.
- `5 в работе`, `5 выполнен`, `отмени заказ 5`: смена статуса.
- `назначь 5 на Ивана`: ручное назначение.
- Любой другой текст считается заявкой клиента.

## API

`POST /api/dispatcher/chat {text}`, `GET/POST /api/orders`, `PATCH /api/orders/:id`, `POST /api/orders/:id/assign {masterId?}`, `GET/POST /api/masters`, `PATCH /api/masters/:id`, `GET /api/orders/export` (Excel), `GET /api/events` (SSE для живого обновления).

# Радар заработка (`/radar`)

Каждые 30 минут обходит источники, оценивает каждую находку по шкале 0–100 («насколько на этом можно заработать») и присылает на телефон самое сильное. Для каждой находки готовит сценарий рилса, собирает вертикальное видео 1080×1920 и может само опубликовать его в Instagram.

## Источники

| Источник | Что даёт | Нужно |
|---|---|---|
| Hacker News · Show HN | новые продукты и стартапы с первыми клиентами | — |
| Product Hunt | запуски продуктов дня | — |
| Google Trends RU / US | что сейчас ищут люди | — |
| vc.ru, RB.ru, Хабр · Стартапы | рынок и бизнес в России | — |
| TechCrunch, Entrepreneur | инвестиции в компании, идеи | — |
| CoinGecko | тренды крипты | — |
| Reddit (r/sidehustle, r/Entrepreneur и др.) | подработки и кейсы с цифрами | часто блокирует серверы — нужен `RADAR_PROXY` |
| YouTube Shorts | какие ролики про заработок набирают просмотры | `YT_API_KEY` |
| Свои RSS | любые сайты и Telegram-каналы через RSS-мосты | `RADAR_EXTRA_RSS` |

Instagram не даёт API для чужих трендовых рилсов, поэтому что снимать радар понимает по YouTube Shorts, Google Trends и Reddit.

## Как поставить на телефон

1. Сервер должен открываться из интернета по **HTTPS** (без HTTPS push не работает). Например, Render, Railway, VPS + Caddy.
2. Откройте `https://ваш-сервер/radar/` на телефоне.
3. **Android (Chrome):** меню ⋮ → «Установить приложение». **iPhone (iOS 16.4+):** «Поделиться» → «На экран Домой», затем откройте радар **с иконки**.
4. Настройки → «Включить уведомления» → «Проверить».

Дублировать уведомления в Telegram: `TG_TOKEN` + `RADAR_TG_CHAT_ID` (или общий `TG_CHAT_ID`).

## Рилсы и Instagram

- В карточке находки — сценарий: крючок, текст слайдов, призыв, подпись, хэштеги, как снять самому. Всё можно отредактировать.
- «Собрать видео» делает MP4 через ffmpeg (на сервере нужен `ffmpeg` и шрифт с кириллицей, например `fonts-dejavu`).
- «Опубликовать в Instagram» использует официальный Graph API. Нужно:
  1. Профессиональный аккаунт Instagram (Бизнес или Автор).
  2. Приложение на developers.facebook.com с правом `instagram_content_publish` (для API с входом через Facebook аккаунт должен быть привязан к странице Facebook).
  3. Долгоживущий токен → `IG_ACCESS_TOKEN`, ID аккаунта → `IG_USER_ID`, адрес сервера → `PUBLIC_URL` (Instagram сам скачивает видео по ссылке).
- **Автопубликация** (Настройки): раз в обход берёт свежую находку с оценкой выше порога и без признаков риска, собирает видео и публикует, не больше N в сутки. Новости и тренды автоматически не публикуются. По умолчанию выключена.

Без музыки видео выглядит слабее: для охватов лучше скачать ролик и добавить трендовый звук в самом Instagram.

## Переменные окружения радара

| Переменная | Зачем |
|---|---|
| `ANTHROPIC_API_KEY` | Разбор находок Claude: перевод, «как на этом заработать», 3 шага, бюджет, риски, сценарий рилса. Без ключа — оценка правилами и шаблонный сценарий. |
| `RADAR_PROXY` | `http://user:pass@host:port` — прокси для всех запросов радара (источники, Telegram, Instagram, push). |
| `RADAR_PASSWORD` | Пароль на API радара. **Задайте обязательно**, если сервер открыт в интернет, иначе кто угодно сможет публиковать от вашего имени. |
| `RADAR_INTERVAL_MIN` | Как часто обходить источники, по умолчанию 30. |
| `RADAR_AI_BATCH` | Сколько находок за раз отдавать Claude (по умолчанию 10; разбирается до 2 пачек за обход). |
| `RADAR_EXTRA_RSS` | Свои ленты: `Название|https://site/rss|kind;Другая|https://...` (kind: idea, business, invest, content, trend, news). |
| `YT_API_KEY` | YouTube Data API v3 — тренды Shorts про заработок. |
| `RADAR_TG_CHAT_ID` | Чат для уведомлений радара (с `TG_TOKEN`). |
| `IG_USER_ID`, `IG_ACCESS_TOKEN`, `PUBLIC_URL` | Публикация в Instagram. |
| `IG_GRAPH_HOST`, `IG_API_VERSION` | `graph.facebook.com` / `v21.0` по умолчанию; для входа через Instagram — `graph.instagram.com`. |
| `FFMPEG_PATH`, `RADAR_FONT` | Путь к ffmpeg и к .ttf-шрифту с кириллицей, если не находятся сами. |
| `VAPID_SUBJECT` | `mailto:ваш@email` для push (ключи создаются автоматически и лежат в `data/radar.json`). |

## Оценка 0–100

Без ИИ: «денежные» слова (доход, выручка, MRR, инвестиции, маркетплейс…), вовлечённость (очки, комментарии, просмотры), свежесть и ваши темы (+15 за каждую). Тренды поиска без денежных слов не поднимаются выше 30. С Claude оценку ставит модель: насколько реально заработать обычному человеку в ближайшие месяцы.

Находки с обещаниями «гарантированного дохода», «иксов», ставок и т.п. помечаются ⚠️ и не приходят в уведомления и в автопубликацию. Раздел «Инвестиции» — это сигналы интереса рынка, а не рекомендации покупать.

## API радара

`GET /api/radar/state`, `GET /api/radar/items?category=&q=&min=&sort=new|score&starred=1`, `GET/PATCH /api/radar/items/:key`, `POST /api/radar/items/:key/analyze|video|publish`, `POST /api/radar/refresh`, `PUT /api/radar/settings`, `POST /api/radar/push/subscribe|unsubscribe|test`. С `RADAR_PASSWORD` — заголовок `x-radar-key`.
