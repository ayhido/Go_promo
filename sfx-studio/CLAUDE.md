# SFX Studio

Проект для саунд-дизайна в DaVinci Resolve через Claude Code.

## MCP-серверы (см. .mcp.json)
- `higgsfield` — генерация аудио/SFX/видео/картинок. Тратит кредиты аккаунта Higgsfield.
- `davinci-resolve` — управление Resolve Studio (проекты, таймлайн, медиапул, дорожки). Resolve должен быть запущен, External scripting = Local.

## Правила работы
- Перед генерацией: покажи пользователю список SFX (момент, описание, длительность) и примерную стоимость в кредитах; генерируй только после подтверждения.
- Не удаляй и не перезаписывай существующие клипы и дорожки пользователя. SFX кладёшь на НОВЫЕ аудиодорожки с понятными именами (SFX Hits, SFX Whooshes, SFX Ambience).
- Не заявляй, что звук поставлен, пока не проверил таймлайн через Resolve MCP (количество клипов, таймкоды).
- Если инструмент вернул ошибку — один повтор, затем скажи пользователю, что именно не сработало.
- Генерированные файлы сохраняй в ./assets/sfx/ с именами вида 001_whoosh_00-03-12.wav.
- Отвечай по-русски, кратко.
