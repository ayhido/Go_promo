# SFX Studio с iPhone

DaVinci Resolve управляется только через скрипты на компьютере (Mac или Windows). На iPhone их нет, поэтому есть два варианта.

## Вариант 1 — полный: компьютер работает, iPhone управляет (рекомендуется)
Всё делается на компьютере (Resolve + Claude Code), а вы командуете с телефона.

1. Один раз настройте компьютер: `./setup.sh` (Mac) или `setup.ps1` (Windows), см. README.
2. На компьютере откройте DaVinci Resolve Studio с нужным проектом.
3. В папке `sfx-studio` в терминале запустите:
   ```
   claude remote-control
   ```
   (или включите Remote Control в Claude Desktop: Settings → Claude Code → Remote Control и выберите папку `sfx-studio`).
4. На iPhone откройте приложение **Claude** → раздел **Code** → выберите сессию своего компьютера.
5. Напишите `/sfx кинематографичный стиль`, проверьте таблицу звуков и подтвердите.
   Результат появится в Resolve на компьютере.

Компьютер должен быть включён, не спать, а Resolve — открыт.

## Вариант 2 — только iPhone, без компьютера (упрощённый)
Автоматической раскладки на таймлайн не будет: звуки генерируются, а ставите вы их сами.

1. В claude.ai (через браузер) подключите Higgsfield: Settings → Connectors → Add custom connector →
   URL `https://mcp.higgsfield.ai/mcp`, затем войдите в Higgsfield. Коннектор появится и в приложении Claude на iPhone.
2. В приложении Claude опишите ролик и попросите: «Составь список SFX с таймкодами для этого видео и сгенерируй их через Higgsfield».
   Можно прикрепить скриншоты ключевых кадров.
3. Скачайте полученные звуки в «Файлы» и вставьте их в монтажное приложение на телефоне по таймкодам из списка.

Не проверено: точные названия пунктов меню могут отличаться в зависимости от версии приложения и тарифа.
